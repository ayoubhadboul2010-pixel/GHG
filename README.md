# GHG Empire — Telegram Mini App (Updated 2026-11-06)

واجهة Telegram Mini App عربية للعبة رصيد افتراضي GHG. يتضمن هذا الإصدار ملفًا شخصيًا للمحفظة والسحب، وسجل الطلبات، ولوحة إدارة للموافقة والرفض وتسجيل معاملة الدفع.

## قواعد اللعبة المضافة
- سرعة التعدين الأساسية: **0.01 GHG/s** = 0.6 في الدقيقة = 36 في الساعة = 864 في 24 ساعة.
- دعوة لاعب جديد عبر رابط الدعوة تمنح صاحب الرابط **500 GHG** مرة واحدة لكل Telegram user ID جديد.
- تكلفة الترقية: **0.01 TON**، وتضيف **0.01 GHG/s** فقط بعد أن يتحقق الخادم من وصول المعاملة بالتعليق الفريد والمبلغ المحدد.
- سعر السحب: **20,000 GHG = 1 TON**، والحد الأدنى **2,000 GHG = 0.10 TON**.
- السحب يتطلب حسابًا موثقًا ومحفظة مربوطة. عند إنشاء الطلب يُحجز رصيد GHG؛ الرفض يعيد الرصيد تلقائيًا.

## ملف اللاعب
- ربط محفظة TON عبر TON Connect وحفظ عنوانها.
- فصل المحفظة من حساب اللعبة.
- إنشاء طلب سحب بالمبلغ الذي يختاره اللاعب (بحد أدنى 2,000 GHG).
- عرض سجل آخر 30 طلب سحب وحالتها ورقم المعاملة عند تسجيله.

## لوحة الإدارة `/admin`
- عرض طلبات السحب ومعلومات اللاعب والمحفظة والمبلغ.
- الموافقة على الطلب.
- رفض الطلب وإرجاع GHG تلقائيًا.
- بعد إرسال TON يدويًا، إدخال رقم المعاملة لتسجيل الحالة `paid`.
- صفحة الإحصائيات وتعديل رصيد لاعب.

## الإعداد والنشر
1. انسخ `.env.example` إلى `.env` محليًا، أو أدخل المتغيرات في Render Environment.
2. اضبط `BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL`, `ADMIN_IDS`, `SECRET_KEY`, `DATABASE_URL`.
3. اضبط `TON_RECEIVE_ADDRESS` و`TONCENTER_API_KEY`.
4. انشر على HTTPS، وافتح `/health` للتأكد من التشغيل.
5. TON Connect manifest يُقدّم من `/tonconnect-manifest.json` ويستخدم `WEBAPP_URL`.

## ملاحظات أمنية مهمة قبل تفعيل الأموال الحقيقية
- **السحب يدوي**: الموافقة لا ترسل TON تلقائيًا؛ على المشرف إرسال المبلغ من محفظة المشروع ثم تسجيل hash المعاملة.
- ربط TON Connect يحفظ عنوان المحفظة الذي يقدمه العميل، لكنه ليس إثبات ملكية مستقلًا. قبل إطلاق السحب العام، أضف challenge موقّعًا/إثبات ملكية للمحفظة.
- مكافأة الدعوة مرة واحدة لكل Telegram user ID. لا يمكن للنظام وحده إثبات أن عدة حسابات Telegram ليست لشخص واحد؛ مقاومة الحسابات الوهمية تحتاج قواعد إضافية ومراجعة/حدود ومكافحة إساءة الاستخدام.
- التحقق الحالي من معاملات TON آلية أولية تعتمد TON Center v2؛ يجب اختبار التعليقات والمبالغ والعنوان ونهائية المعاملة، ويفضل استخدام indexer/webhook موثوق قبل الإطلاق.
- قاعدة SQLite على Render Free غير مناسبة للبيانات المالية الدائمة؛ استخدم PostgreSQL أو قرصًا دائمًا ونسخًا احتياطية. لا تعتمد على خدمة مجانية بلا تخزين دائم لأرصدة المستخدمين.
- لا تضع Bot Token أو TON Center API Key في ملفات الواجهة أو GitHub. خزّنها في Environment فقط.
- المشروع يحتاج اختبارًا أمنيًا وماليًا شاملًا قبل قبول مدفوعات أو تحويل TON حقيقي. GHG رصيد لعبة افتراضي وليس عملة مشفرة مستقلة.

## تشغيل محلي
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```


## حالة الاختبار لهذه الحزمة
- تم فحص صياغة ملفات Python وتجهيز حزمة ZIP من ملفات المشروع.
- لم يتم نشر هذه الحزمة إلى GitHub أو Render تلقائيًا، ولم يتم تنفيذ تحويلات TON حقيقية.
- يجب اختبار ربط المحفظة والتوثيق والترقية والسحب على شبكة اختبار قبل تفعيل أموال حقيقية.
- واجهة الرفض تعيد رصيد GHG المحجوز إلى اللاعب، وتسجيل `paid` يتم بعد إدخال المشرف رقم معاملة TON يدويًا.
